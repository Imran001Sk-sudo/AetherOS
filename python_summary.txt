================================================================================
                    PYTHON 3.14 - LATEST FEATURES & UPDATES SUMMARY
================================================================================
Expected Release Date: October 2025 (Alphas/Betas ongoing throughout 2024-2025)

--------------------------------------------------------------------------------
1. CORE LANGUAGE & SYNTAX ENHANCEMENTS
--------------------------------------------------------------------------------
• Deferred Evaluation of Type Annotations (PEP 649 / PEP 749):
  - Type annotations are now evaluated lazily on demand when `__annotations__` is 
    accessed rather than at module/class/function definition time.
  - Significantly reduces import times and resolves forward reference issues cleanly.

• Template String Literals / t-strings (PEP 750):
  - Introduces template strings (syntax: t"...") enabling safe, custom interpolation,
    contextual escaping, and domain-specific string templates (e.g., HTML, SQL, shell).

--------------------------------------------------------------------------------
2. CONCURRENCY & PARALLELISM UPDATES
--------------------------------------------------------------------------------
• Multiple Subinterpreters (PEP 734):
  - Exposes subinterpreters directly via the standard library (`concurrent.interpreters`
    or `interpreters` module), enabling true multi-core parallel execution with 
    isolated interpreter states.

• Free-Threading (No-GIL) & JIT Advancement (PEP 779):
  - Further stabilization and enhancements to the free-threaded build (GIL disabled).
  - Continuous performance optimizations to the experimental Copy-and-Patch JIT compiler.

--------------------------------------------------------------------------------
3. STANDARD LIBRARY & SYSTEM UTILITIES
--------------------------------------------------------------------------------
• Built-in Zstandard Compression (PEP 784):
  - Adds native support for Zstandard compression in the standard library (`compression.zstd`).

• Safe External Debugger Interface (PEP 768):
  - Provides a standardized, safe API for external debuggers and profilers to inspect 
    running Python processes.

• Interactive REPL & Usability:
  - Enhanced colorized tracebacks and improved terminal REPL experience carried forward 
    and refined from Python 3.13.

--------------------------------------------------------------------------------
4. SECURITY, BUILD & INFRASTRUCTURE
--------------------------------------------------------------------------------
• Sigstore Verification & Removal of PGP Signatures (PEP 761):
  - Deprecates/removes PGP signatures for official release artifacts in favor of 
    Sigstore digital signatures.

• C-API Modernization & Cleanup:
  - Continued removal of deprecated APIs, improved static inline functions, and better
    support for custom memory allocators and isolated interpreter instances.
